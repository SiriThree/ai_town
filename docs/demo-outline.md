# 3–5分钟演示提纲（建议4分30秒）

这是录制提纲，不代表视频已经完成。全程使用真实运行页面；正式录像前关闭无关标签，使用专用演示世界，先确认数据库与AI可达，准备一个独立无密钥服务。不要在录屏中打开.env文件、终端历史或供应商控制台密钥。

| 时间 | 画面与操作 | 讲解要点 |
|---|---|---|
| 0:00–0:35 | 默认街区，点阿晴/阿宁，打开档案 | 两个性格、三个地点；饥饿越高越饿，精力越高越好。页面通过API读已保存状态，人物不是随机巡游。 |
| 0:35–1:15 | 开始自动运行，观察一步行走，再暂停 | 5秒逻辑间隔；规则按需求和性格选择合法动作，后台提交路径、前端播放。打开第二标签也不双倍加速；无人访问不运行。 |
| 1:15–1:55 | 展示食物前饥饿值→送食物→档案→推进 | 实际改变饥饿，后续决策读取新状态。使用隔离种子可演示59→24，下一步由去咖啡馆变为社交；不得把当前自然状态硬说成一定触发同样决策。可切到控制变量测试结果说明。 |
| 1:55–2:40 | 点阿晴，问“你现在在哪、做什么”；展开气泡全文 | 显示AI来源。请求快照包含真实地点/行动，过去聊天另标时间；旧气泡在世界更新后标历史。模型只说话，不拥有世界修改工具。尽量只发一条必要真实请求。 |
| 2:40–3:10 | 切独立无密钥实例；同样提问 | 显示“降级回复”，仍按人设/状态回答。503和超时已由本机故障替身验证，不能称替身是真实模型。若现场供应商失败，如实展示Fallback。 |
| 3:10–3:40 | 暂停后刷新；重启演示后台，核对版本与档案 | PostgreSQL存档；行锁和版本冲突保护；重启不重置。只重启本项目演示进程，不重置数据库。 |
| 3:40–4:15 | 展示一张V2.1证据和当前气泡效果，简述调用链 | “我审查AI生成的大Modal，判断它偏离游戏体验，提出场景气泡和轻输入方案、限定不改后台，由AI实现后继续验收。”不要声称手写源码。 |
| 4:15–4:30 | 回小镇，展示README入口 | 单共享世界/会话、额度和访问有效期；说明尚无经济/室内系统，不扩大MVP。线上地址部署后再填；未上线时展示本地替代。 |

录制前核对：1366×768或1440×900；隐藏所有真实密钥；世界版本与两名NPC清楚；准备源码关键位置`world.ts`、`store.ts`、`chat-context.ts`、`scene-motion.ts`以便面试追问。录像应包含本人声音，保持3–5分钟；V4.2/V5.1短动画录屏仅作为证据，不能冒充讲解视频。
