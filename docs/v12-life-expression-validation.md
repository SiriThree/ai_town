# V12-L 居民生活表达验收

本轮只增加有来源的生活表达、内心观察和原自主交流的适度调整。地图、居民数量、职业、私人记忆、世界时钟和行动结算保持原结构。开始基线 `de3496a`，已有 V11.7 等未提交修改全部保留；没有推送、部署或重置主世界。

## 原实现与问题定位

`social.canTalk / beginSocial` 已有真正的近距离交流：同场景、距离不超过100、无行走路径、没有不可中断行动、需求允许、存在社交动机。原来熟悉度需5，外向居民心情需低于85，每人冷却120世界分钟，全局30分钟、每日8次上限。路径只是经过、忙于工作或正在赴约均不会交流；这些条件叠加令可观察窗口很短。保留可解释限制，不让全体居民随时闲聊。

正式交流已有2句顺序时间线，每句5秒模拟行动时间，结束后下一步重新决策；不会等待模型结果推进世界。`social-service` 的可选模型增强仍用原预算/超时/额度。原来没有独立的自言自语和内心字段，仅有 mood 与有来源经历中的 opinion；没有把模型推理当作内心。

原气泡是 HTML 叠加在 Pixi 场景上，通过真实角色动画 pose → `bubblePlacement` → 当前镜头坐标定位。玩家回复优先，随后是当前正式交流；不会重新建一套 Pixi 气泡或事件总线。

## 新记录与调用链

`advanceWorld → progressAction/settleWork → beginSocial/observeEncounters → observeLife → 原行锁事务保存 → /api/world → TownScene`。

世界 JSON 增加可选 `lifeExpressions`（最多120条），不新增表、不迁移正式数据。旧存档没有字段时原样读取，下次真实事件才产生记录。每条含稳定 ID、居民、场景、世界分钟、版本、speech/thought、主题、短句，以及来源行动 ID、可用的结算事件 ID、当时行动/需求快照。较老的完整行动事件可能随原日志上限滚出，但这份有限观察记录保留来源标识与快照。

触发：真实开始工作、长于500坐标单位的路径、开始休息/阅读/等待、开始新行动时饥饿或疲惫、工作步骤确实增加、吃饭/休息需求实际改善、行动因实际条件中断。工作步骤完成只说“一步/这一段”，不冒充整份工作完成。观察只附加记录，不修改需求、路径、关系、工作产出或约定。

每居民36世界分钟冷却，同主题180分钟去重；合格事件按稳定哈希65%采样。事务重试与读档重放不产生随机新台词。内向/外向采用不同本地表达，文本最多30个可见字符。本轮没有新增模型调用。

内心观察是对玩家可见的主观表现，不是 NPC 听到的事实；不写入 `experiences`、世界事件、关系或模型公共上下文。不读取访客名称、私人对话或私人约定原文。完整最近6条观察在居民详情“生活片刻”中按需打开，来源信息仅诊断模式显示。

## 交流与气泡

复用原2轮对话和同一会话身份，不新增第二套会话：每人冷却由120调至90世界分钟，熟悉动机阈值5调至2，外向心情阈值85调至90；真实共同工作经历也可形成动机。每日8次、全局30分钟、距离、路径和工作保护仍在。补上已到场等待及执行目标期间不能被普通聊天打断。问候按时间和性格有少量变化，有共同工作/聚会时引用对应真实来源。寒暄仍只增加熟悉度，不增加信任。

优先级：玩家对白 > 正式交流 > 自言自语 > 内心观察。采用保守的全视口单个生活气泡，避免同一角色或多个生活气泡重叠；在当前场景、可视范围内选择。生活气泡最多显示6秒（独立 UI 定时，暂停世界也能消失），世界来源超过12分钟不再展示。思想采用虚线圆角及小圆点尾巴、“心想”文字区分。位置继续追随真实 pose、缩放和平移，离屏隐藏。完整短句不丢失。

## 限制

本地词库有限，冷却后仍可能重复同主题表达；这不等于 LLM 自由生成内心。内心只反映有限当前处境，没有新增心理模拟。每次正式交流仍为2句，并非长篇社交。全局保守优先级可能让另一居民的低优先级气泡被隐藏。没有新增费用、关系结算或为录屏改变正式世界。
